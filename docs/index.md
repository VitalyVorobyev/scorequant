# ScoreQuant documentation

ScoreQuant chooses hard bins from model scores to retain Fisher information at a reference
parameter point. Use `optimize_partition` for labels on a fixed sample, or `fit_quantizer` for
a reusable rule. Estimated scores produce a surrogate information measure.
