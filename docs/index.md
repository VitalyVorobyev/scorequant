# ScoreQuant reference

ScoreQuant chooses hard bins from model scores to keep Fisher information at a reference
parameter point. Use `optimize_partition` for labels on a fixed sample, or `fit_quantizer` for a
reusable rule.

This site is the reference. To learn the ideas and see them at work, start with the
[learning portal](https://vitalyvorobyev.github.io/scorequant/): a first fit, four walkthroughs
with live demos, and short explainers.

- [User guide](guide.md): how the pipeline works and which task, input, criterion and solver to use.
- [API guide](api.md): every public name, its contract, guarantees and refusals.
- [Symbol reference](symbols/index.md): signatures and docstrings.
- [Glossary](glossary.md).
