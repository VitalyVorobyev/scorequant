Because every global optimum is realizable as a nearest-centre labelling (`D-GLOBAL-GEOMETRIC-REALIZABILITY`), an arrangement enumeration solves the finite determinant problem exactly, in time polynomial in the sample size for a fixed parameter dimension and cell count. This is a direct application of a known enumeration template rather than a new algorithmic idea; whether the resulting exponent is tight is a separate, open question (`OPEN-D-PARAMETERIZED-COMPLEXITY`).
