# Get started

ScoreQuant turns score vectors into a few hard labels that keep as much Fisher information as possible. You supply one score vector per event; ScoreQuant chooses the bins and reports what they kept.

This page fits a rule, uses it on new data and saves it. The <Link to="/walkthroughs">walkthroughs</Link> follow complete problems, and the <ReferenceLink to="guide/">user guide</ReferenceLink> covers inputs, criteria, solvers and nuisance parameters.

## Install

```bash
uv add scorequant
```

or `pip install scorequant`, on Python 3.12 or newer.

The **D-efficiency** is the share of the information the five labels keep, averaged geometrically over the parameter directions; one would mean nothing was lost. The **effective rank** counts the directions the labels still see. A rank below the number of parameters means a direction is gone, whatever the average says.

## Backends and precision

JAX is the default backend; NumPy is the portable one, and the one your browser runs. JAX computes in single precision unless the application turns on 64-bit mode, which the library never does for you. The cells above pass an explicit NumPy, double-precision, CPU execution so that the output printed here is the output you get. The <ReferenceLink to="api/#execution">API guide</ReferenceLink> has the details.
